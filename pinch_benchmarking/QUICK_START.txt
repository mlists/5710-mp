AMME5710 - COMPLETE PINCH BENCHMARK
==================================

1. Open Terminal/PowerShell in this folder (recommended Python 3.11 or 3.12).
   python -m pip install -r requirements.txt

2. Optional: verify the SOFTWARE with synthetic tests, not real accuracy data.
   python -m unittest discover -s tests -v

3. Preview the distance/orientation/negative-control capture plan.
   python pinch_benchmark_run_protocol.py --session session01 --camera 1 --dry-run

4. Record the trials, following the prompts.
   python pinch_benchmark_run_protocol.py --session session01 --camera 1

   Camera is MIRRORED horizontally by default (selfie view).
   To turn this off, add --no-mirror to the recording command.
   The video, MediaPipe landmarks and annotation tool share the same orientation.
   If camera 1 does not open, use --camera 0. With Windows camera problems,
   try --backend msmf. For AVI video fallback, add --video-codec MJPG.

5. Independently label every required clip in its RAW video.
   python pinch_benchmark_annotate.py --session session01 --clip-id distance_35cm_01 --assume-visible

   s = first visible fingertip contact (START)
   r = first visible fingertip separation (RELEASE)
   a/d = step frames, j/l = skip 10 frames, u = uncertain
   v/n/b = hand PRESENT/ABSENT/UNKNOWN, q = save and exit
   f = FINALIZE after reviewing the entire recording

   Repeat for distance_60cm_01, distance_100cm_01,
   orientation_front_0deg_01, orientation_side_45deg_01,
   orientation_side_75deg_01, negative_open_palm_01,
   negative_pointing_01, negative_closed_fist_01, negative_waving_01.
   Pilot is excluded from the main evaluation by default.
   For negative controls, verify that NO physical pinch occurred before
   finalising the clip with zero event labels.

6. Evaluate the SAME recorded landmarks under 1/3/5 confirmation frames.
   python pinch_replay_evaluate.py --session session01 --frames 1 3 5 --tolerance 0.5

7. Open session01/results/ for:
   per_clip_metrics.csv, per_condition_metrics.csv,
   confirmation_ablation.csv, event_matching_audit.csv,
   replay_predictions.csv, summary.json,
   table_conditions.tex, table_negative.tex, table_ablation.tex,
   and publication figures (PNG + PDF).

CORE BASELINE: pinch=.30, release=.35, frames=3, lost_frames=6.
Original detector logic is preserved and original standalone demo is unmodified.
NO real performance results are included. See README.md for full instructions.
